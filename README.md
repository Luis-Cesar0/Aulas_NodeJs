# Aulas de Node.js — Geração Tech

Material didático desenvolvido e utilizado nas aulas de Node.js que ministrei como Instrutor Full Stack no Geração Tech.

O repositório reúne exemplos introdutórios de backend e JavaScript no ambiente Node.js, cobrindo fundamentos utilizados nas aulas práticas.

## Conteúdo

- Módulos CommonJS
- Servidor HTTP
- Leitura e gravação de arquivos
- Manipulação de dados JSON
- Lógica com JavaScript
- Classes e composição
- Encapsulamento
- Herança

## Como executar

Os exemplos são arquivos independentes. Não há `package.json` nem scripts de execução compartilhados. Com Node.js instalado, abra o terminal na raiz do repositório e execute o arquivo desejado, por exemplo:

```bash
node node01/olaMundo.js
```

Para executar outro exemplo, substitua o caminho pelo arquivo correspondente. O exemplo `node01/atividade1/app3001.js` inicia um servidor HTTP na porta 3001.
