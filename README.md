# Exemplos de JavaScript e Node.js

Repositório com exercícios independentes sobre lógica, orientação a objetos e recursos básicos do Node.js. Os arquivos estão separados por assunto e atividade.

## Conteúdo

- Módulos CommonJS e servidor HTTP
- Leitura e gravação de arquivos e dados JSON
- Classes, encapsulamento, herança e composição
- Exemplos de lógica e orientação a objetos

## Como executar

Os exemplos não têm um package.json ou scripts compartilhados. Com Node.js instalado, execute um arquivo individual a partir da raiz, por exemplo:

    node node01/olaMundo.js
